# Student Details CRUD React Project

This is a frontend React project with:

- Login page
- Student CRUD dashboard
- Add student
- Display student details in a table
- Edit student
- Delete student
- Search student details
- Data saved in SQLite database (`students.db`)

## Login Details

```text
Username: admin
Password: 12345
```

## Run

Run the local server from this folder:

```powershell
node server.js
```

Then open:

```text
http://localhost:3000
```

The database file is created automatically:

```text
students.db
```

## Deploy

This project needs Node hosting because it has API routes and SQLite database logic.

Recommended Render settings:

```text
Build Command: npm install
Start Command: npm start
```
